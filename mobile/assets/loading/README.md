# Loading screen artwork

Approved dark sticker-wall design with a street-map overlay. Generated with the built-in imagegen tool on 19 October 2026, then separated into responsive foreground/background layers. `dark-map.jpg` is optimized from the generated PNG; `pin-sticker.png` preserves transparent alpha.

The title is rendered with the app’s actual bundled SpaceGrotesk_700Bold font, and the loading bar is indeterminate (not a percentage). The foreground scales to fit the screen; only the decorative backdrop crops. The personal export includes the same screen before JavaScript starts and caches all artwork/fonts for offline launch. Android’s system splash uses a smaller pin inside its circular safe area, then hands over to the full design.
